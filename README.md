## Overview

This project contains a full equity research report and valuation model for Inditex (BME: ITX), the parent company of Zara.

The report includes:

- Company analysis
- Industry analysis
- Discounted Cash Flow (DCF) valuation
- Trading comparable company analysis
- Sensitivity analysis
- Scenario analysis

The research concludes that Inditex shares were materially overvalued as of 30 July 2026.

---

## Key Findings

- Base Case DCF: €34.36/share
- Current Market Price: €57.28/share
- Implied Downside: 40%
- EV/EBITDA Comps: €31.64/share
- EV/Sales Comps: €36.92/share
- Market Implied Beta: 0.46
- Historical Beta: 0.90
