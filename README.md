## Overview

This project contains a full equity research report and valuation model for Inditex (BME: ITX), the parent company of Zara.

The report includes:

- Company analysis
- Industry analysis
- Discounted Cash Flow (DCF) valuation
- Trading comparable company analysis
- Sensitivity analysis
- Scenario analysis

The research concludes that Inditex shares are modestly undervalued as of 30 July 2026, supported by a structural quality premium, a meaningful Americas growth runway, and a fortress balance sheet.
